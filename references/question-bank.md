# 题库与面试形式打法

按面试形式分组。每种形式准备什么不一样，先判形式再出题。

## 一 · 形式对照表

| 形式 | 题目形态 | 必须额外准备 | 关键风险 |
|---|---|---|---|
| 结构化（几对一） | 主问题 + 追问 | **追问树**（同题往下 5 层） | 追问层露怯 |
| 群面 / 无领导小组 | 讨论题，1 小时内 | 站位、抢话节奏、收束、汇报 | 一直点头最后被归进"没怎么说话的人" |
| AI 视频（ HireVue 型） | 1–2 题，60–90 秒 | 连贯完整稿、镜头感、不念稿 | 说满时间但没有结论 |
| 压力面 / 深挖 | 从简历某点切入 | 深挖链、失败题、压力题 | 越挖越慌 |
| 案例题 / 笔试作业 | 限时写 | 框架 + 数据 + 结论 + 风险 | 结构不完整 |
| 电话初筛 | 5–15 分钟 | 60 秒自我介绍 + 为什么 + 到岗时间 | 没准备就答，浪费一个机会 |
| 英文场 | 同上但英文 | 术语中英对照 + 英文逐字稿 | 中文能说、英文卡壳 |
| HR 面 / 终面 | 稳定性、动机、offer | 反问、谈薪口径、离职原因 | 反问没问出真信息 |

## 二 · 结构化面试的追问树

**规则**：每个主问题向下追 5 层，且每一层都必须能落到用户的真实素材上。
追到第 5 层还没有数字，就是没准备完。

树的标准形状（以"讲一段实习"为例）：

```
L0 讲一段你最有成就感的实习
L1 这段实习你具体负责什么？（要动作，不要职责）
L2 你做的判断依据是什么？（要变量、要口径）
L3 如果数据变一下，你的结论会变吗？（要边界，要压力测试）
L4 别人不同意你，你怎么处理？（要真实冲突）
L5 事后看，这件事你会怎么改？（要自我认识，不要自夸）
```

每层写：**追问原文 + 答题要点 + 用户素材挂载点 + 禁答**。

挂载点要写清"这一层用某地产公司区域投决的哪一段"，否则模型（和用户）回答时会临时找素材，
说出的话和主线脱节。

### 追问树的常见形状（可复用）

- **"为什么转行"型**：为什么转 → 什么时候决定的 → 当时还有什么选择 → 家里人怎么看 → 如果转错了怎么办
- **"讲经历"型**：做了什么 → 怎么做 → 难在哪 → 怎么解决 → 结果如何量化
- **"观点"型**：你的判断 → 依据 → 反例 → 边界条件 → 你可能错在哪
- **"抗压"型**：压力源是什么 → 你的应对 → 代价是什么 → 怎么恢复 → 现在还会被同类事困扰吗

## 三 · 群面打法骨架

每道群面题按七块写（照搬这个结构，不同题只换内容）：

1. **题眼拆解**：这题真正在问什么 + 三个常见陷阱
2. **三个站位**：至少一个推荐站位（含核心论点、风险、补救）
3. **90 秒逐字稿**：三段式（重新定义题目 → 给判据 → 自己的例子 → 人话收尾）
4. **高分句**：3–5 句可直接用
5. **抢话节奏**：第 1–2 分钟 / 中段 / 快结束 / 总结，各给句式
6. **禁语**：5 条，带"为什么会被判负分"
7. **追问**：4 个大概率追问 + 答法

### 通用判据（任何群面题都能套）

群面题几乎都是伪二选一。高分答案的共同结构是：
**把"选 A 还是 B"重新定义成"用哪个规则来选"**，然后给 2 个可操作的判据，
再挂一个真实例子。

常见可迁移的判据类型：
- 冲突的**期限**不同（短期杠杆 vs 长期议价能力）
- 冲突是**信息问题**还是**利益问题**（前者根本不是抉择，是沟通没做够）
- 冲突是**一次性**还是**结构性**（结构性冲突妥协一次会变成惯例）
- 压力来自链路的**哪一段**（漏斗：获客 / 转化 / 留存）
- 哪一边是当前的**约束条件**（先解除约束，而不是选边）

### 抢话节奏（内向型用户的具体设计）

内向不等于话少，风险是"一直点头最后被归进没怎么说话的人"。要设计三件事：

1. **抢第一个结构化发言**：哪怕不是第一个说，也要是第一个给出"重新定义题目"的人
2. **固定开口句式**：提前背 2 个推进句式（"我们是不是漏了一个维度……" /
   "我补一个前提——如果……结论就要反过来"），被点名时直接用
3. **汇报时自报贡献**：开口第一句就认领"我主要负责的是……"

被打断：不争，让出话轮，记下接话点，30 秒内用推进句式重新进。
被反驳：先承认对方的合理之处，再用转折句式接住；不要说"我觉得不是这样"然后辩护。

## 四 · 个人化问题

三类各准备三档话术：

| 类型 | 触发时机 | 三档 |
|---|---|---|
| 主动讲 | 有利时机（讲抗压/韧性时） | 主动讲 / 被问才讲 / 明确不需准备 |
| 被问才讲 | 面试官直接问 | 同上 |
| 不需准备 | 制度上无影响且现实风险低 | — |

写法上要点：
- 先讲**事实与制度**，不辩解、不道歉
- 结论要落在**能力**上（这件事需要什么能力，我有什么）
- 策略上优先"**把顾虑转成岗位问题**"——反问"这个岗位日常对外的比例大概多少"
  比重申"我不是您想的那种"更有效

## 五 · 反问

分四类工具箱（每类给 2–3 个具体问法）：

1. **业务类**：这个岗位今年最看重哪类资产/哪类项目？
2. **机制类**：从投前到投后，时间怎么分配？决策点在哪？
3. **考核类**：KPI 是什么？什么样算做好了？
4. **成长类**：新人前半年通常怎么带？

再加**时机与框定**（什么时候问、问几个）和**禁问清单**（福利细节在 HR 面才问、
不要问"能加微信吗"）。

反问的判分标准是**有没有问出真信息**——问题本身要能被具体回答。

## 六 · 题目优先级

材料篇幅有限时，按这个顺序取舍（先做的一定是高频高频）：

1. 自我介绍 + 为什么这个岗位 + 为什么从 X 转 Y（必答，占分最大）
2. 讲一段实习 + 追问树（必答，最容易深挖）
3. 怎么看行业/公司（必答，暴露准备程度）
4. 职业规划 / 稳定性（HR 必问）
5. 群面题（若本场有）
6. 反问（人人都要，差距在问什么）
7. 个人化问题（低频但一题定生死，必须备）
8. 价值观 / 哲学题（可临场，但备一句锚句）
