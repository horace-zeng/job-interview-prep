# 多岗位对比与面试复盘

多岗位同时推进、或面试已经发生过时用这两张表。它们的价值在于**把"感觉没答好"变成可执行清单**。

## 一 · 岗位对比表

一行一个岗位。列的选择标准：能直接支撑"投哪个、怎么投"。

| 列 | 内容 | 注意 |
|---|---|---|
| 公司 / 岗位 / 城市 | 基本信息 | 同一集团不同事业部的岗位要分行 |
| 岗位性质 | 校招 / 社招 / 管培 / 实习转正 | 影响考察重心 |
| 面试形式 | 轮次、几对一、有无群面/笔试 | 各自要准备的东西不同 |
| 时间线 | 投递日 / 笔试 / 面试日 / 出成绩 | 决定取舍，撞期要早说 |
| 我们的强项 | 与该岗位最相关的 2–3 条 | 从素材库按岗位重排，不是一套通用清单 |
| 明显短板 | 最容易被问倒的 1–2 条 | 要具体到"哪一类问题会露" |
| 竞争烈度 | 岗位数 vs 投递人数 / 行业热度 | 决定要不要继续投入时间 |
| 需要额外准备 | 该岗位特有的材料 | 比如英文版、行业知识、案例作业 |
| 决策条件 | 什么情况下放弃这个 offer | 提前定，避免到时凭情绪 |

用法：把"强项/短板"两列横向对比，通常能直接看出**该主攻哪个**、**另一个该补什么**。

## 二 · 面试复盘表

### 2.1 逐题判分

只判内容，不猜面试官的心理（猜了也没法验证，还会误导用户）。

| 题 | 我答了什么 | 缺什么 | 补法 | 是否复现 |
|---|---|---|---|---|

"我答了什么"用用户的原话或要点，不要润色。
"缺什么"要落到可补的动作：缺一个数字、缺一个反问、缺一个转折点。
"是否复现"标这是第一次/上一场也这样——**重复出现的问题才是真问题**。

### 2.2 硬失分点清单

按"最可能让你被刷掉"排序，不按出现顺序。每条写：

```
失分点：具体哪里丢分
为什么丢：机制层面的原因（不是"你紧张"）
下次怎么改：一个具体动作
```

常见硬失分点（作为检查表）：
- 答案没有落点，停在"我会努力"这类表态
- 全程没提数字
- 被追问时开始重复第一遍的回答
- 反问问了福利细节，把唯一的提问机会浪费掉
- 个人化问题答得防御性过强，抢了评委注意力
- 群面全程点头，没输出结构化观点

### 2.3 亮点清单（对用户价值最高）

用户通常低估自己。需要主动指出：他以为答砸了、但实际答得好的地方。

写法："你在这里说 X 的时候，其实是全场最硬的一句，原因是 Y。"
特别关注：他用真实经历回答抽象题；他主动承认边界；他反问出真信息。

### 2.4 下一场要改的三件事

最多三条，且必须是**动作**不是"多准备"。

坏："多练习"、"加强专业知识"。
好："每一题结尾必须有一句落点句，我给你标出来，你对着练 5 遍"。

## 三 · 复盘的输入从哪来

- 用户口述的面试过程（**第一手，优先**）
- 面试官当场问的原话（越具体越好）
- 用户之前准备的材料（对照他实际说的，看偏离在哪）
- 公开面经（用来判断题目是否典型，不用来猜评分）

用户没说过的现场细节**不要补写**。复盘里出现"你当时其实是紧张了"这种推断，
要明确标成"这是我的推断，不是你说的"。

## 四 · 复盘的输出节奏

先给**三句话结论**（这场最大的问题 / 最大的亮点 / 下一场改什么），
再给表格。用户要的是判断，不是档案。

## 五 · 跨轮次衔接

同一岗位多轮时（初面 → 复面 → 终面 / HR 面），记录每轮问了什么，
下一轮的准备从"上轮被问到的 + 还没问过的核心题"两头取。

轮次之间的常见变化：
- 初面考"你能不能做" → 复面考"你做不做得成" → 终面/HR 考"你会不会留下"
- 每轮都会出现一个新问题类型（技术面出业务题、HR 面出价值观题）
- 最后一轮往往是团队负责人面，考的是"和这群人合不合"

对应准备：越往后越少讲方法论，越多讲"为什么是这家公司、为什么是现在"。
