# 答案三段式写法

每一道题都按 **关键词 → 思考逻辑链 → 完整回答** 三段写。三段各有各的用处，
不要合成一段"参考话术"糊过去。

## 一 · 三段各自的职责

### 1. 关键词

说出来时脑子里要有的东西，不是要背的句子。用名词短语，不要用完整句。

分两栏，都写：

- **锚点词（3–5 个）**：这题的骨架，紧张时看一眼就能续上
- **可替换表述池**：更细的措辞、数字、术语，按场景取用（可以超过 5 个）

例（"为什么从建筑来干投资"）：
- 锚点词：`方法论迁移 · IRR 从零搭 · 单地块→区域组合 · 导师否定后重推结构 · 投委会一次过审`
- 表述池：`5 变量 18 张独立表 · 地价+10%×去化−15% · 投决一次过审 · 模型沿用两月 · 懂建造的投资岗`

原因：锚点词是**记忆负担的上限**（3–5 个才记得住），表述池是**说法的弹药库**。
只写 3–5 个会丢掉细节，只写一堆又记不住——两栏各司其职。

### 2. 思考逻辑链

从题眼到落点的推导路径，**标出关键的那一步转折**。这是整份材料里最值钱的部分，
因为它教的是"怎么想"，换个题也能用。

标准写法：

```
题眼：这题真正在问的是什么（不是字面问题）
→ 第一步判据：按什么维度拆
→ 关键转折：我在哪一步改变方向（这里加粗标注"转折点"）
→ 第二步判据
→ 落到用户素材
→ 收尾落点
```

例子（"增长承压时拓张还是维系"）：

```
题眼：不是"拓张重要还是维系重要"，是"我的增长瓶颈卡在增长链的哪一段"
→ 判据一：压力是新增效率问题还是留存问题
→ **转折点：拓张和维系不是对立的两方，是同一条链的上下游**（这里换掉整个框架）
→ 判据二：哪一边是当前的约束条件（看边际回报）
→ 素材：某地产公司区域投决，导师否定"单地块"口径，改成区域组合，报告一次过审、模型沿用两月
→ 落点：单点会骗人，要看组合
```

### 3. 完整回答

可直接说出口的逐字稿。要求：

- **口语**：要有"我先说结论""举个例子""所以"这类连接词，不要写书面语的"首先/其次/最后"
- **有收尾句**：最后一句是能被人记住的短句，落在动作或具体物上，不落在感想上
- **标时间预算**：每层写清楚占多少秒（例：方法论 0–20s / 硬证据 20–55s / 补充 55–80s / 落点 80–100s）。
  用户要靠这个判断"哪句可以临场省略"
- **长度分档**：必备三档——**30 秒**（群面 / 电话初筛）、**60 秒**（常规结构化）、
  **90–100 秒**（主稿）。再加 120 秒深挖版只在被明说"再具体一点"时用；
  结构化面试里超 100 秒会被打断
- **标出删改点**：哪些句子是模板、哪些必须换成用户自己的话

## 二 · 差答案对照

| 差 | 为什么差 | 好 |
|---|---|---|
| "我认为团队和个人都很重要，要平衡" | 没有立场，等于没答 | "真正要选的是冲突发生时靠什么规则" |
| "因为我学的是房地产开发与管理" | 课程名不是证据 | "课上学到的估值方法，是我后来搭 IRR 模型的方法底子" |
| "贵公司是行业龙头，实力雄厚" | 谁都能说 | "贵公司的差异化在存量改造能力，这块和我的建筑背景直接相关" |
| "我在某头部房企做过投资拓展，很有经验" | 没有动作没有数字 | "我 30 天出一份投决报告，IRR 模型从零搭，拆成 18 张互不耦合的独立表" |
| "我性格外向，适合团队合作" | 形容词不是证据 | "8 人项目里我协调 5 方，把甲方从'朝西'这个诉求转到动线方案，提前 3 天交付" |

## 三 · 逐字稿的可背性检查

写完一段逐字稿，自查四点：

1. **能一口气说完吗**（长句要拆断，允许用 `<br>`）
2. **有锚句吗**（第一句和最后一句是不是最有力的两句）
3. **有真实数字吗**（至少一个）
4. **有落点吗**（结尾是动作/事实，不是感想）

## 四 · 材料编排上的分层

不要把所有内容平铺成同一个密度。分层依据是**用途**：

| 层 | 用途 | 特征 |
|---|---|---|
| 背 | 上考场前 15 分钟只看这一页 | 速记卡、锚句清单、硬数字表 |
| 讲 | 完整对话用 | 三段式答案 + 逐字稿 |
| 查 | 被追问时翻 | 术语详解、文件清单、流程表、自测卷 |

同一份材料里同时放这三层，读者才知道先看哪、什么时候翻哪。

## 五 · 弱项怎么处理

用户素材里有弱项（转专业、经历短、没有对口经验）时：

- **不放第一段**，降到最后 15 秒，并主动加限定句（"我知道 X 不是我的主场，所以……"）
- **主动换框**：把弱项转成机制（"我不擅长做判断题，但我擅长把判断变成可验证的数字"）
- **准备一句诚实且有指向的回答**：承认边界 + 给出怎么补的动作
- 不用课程名、证书名、兴趣（炒股等）充数——它们会被读成追高或浅尝辄止

## 六 · 写逐字稿时的常见失误

- 把"关键词"写成完整句子，导致三段内容重复
- 逐字稿里出现没有出处的数字
- 逐字稿用了用户的口头禅，但没有核对过用户真的这么说
- 逐字稿超过 120 秒——结构化面试里超时会打断你
- 只写一段通用话术，没按面试官可能问的方向分档
